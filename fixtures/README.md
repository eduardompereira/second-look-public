# Fixtures — the fictional match

`payload/*.json` is the app's data for a **fictional** final (Harbour HC 5–3 Ridge Academy), generated by
`tools/make_fictional_fixtures.py` from seed 20261112. The generator reads no file; it creates every event, time, position,
outcome, model rating, rank, player and number. `python3 tools/make_fictional_fixtures.py --check` (part of the publish
gate) proves the committed files are exactly what the generator produces.

`setup_fixture.py` copies the payload to where the app reads it and generates labelled placeholder stills and
placeholder video clips (ffmpeg test patterns) under `fixtures/media/` (git-ignored).
